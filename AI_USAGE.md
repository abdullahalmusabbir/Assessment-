# AI Usage Disclosure

## 1. Purpose

This document discloses the use of AI assistance during the planning,
development, documentation, and troubleshooting of the School Admission
System.

## 2. Areas Where AI Assistance May Be Used

AI assistance may be used for: - Explaining framework concepts and
development errors - Drafting project structure and implementation
plans - Suggesting frontend components and UI patterns - Drafting
backend services, DTOs, validation, and API examples - Preparing
database and migration guidance - Drafting documentation and test
checklists - Reviewing code for potential bugs, security concerns, and
consistency issues

## 3. Human Responsibility and Verification

AI-generated suggestions are not automatically correct or
production-ready. The project developer is responsible for:

1.  Reviewing and understanding generated code before using it.
2.  Verifying that code builds and runs in the actual project
    environment.
3.  Checking API routes, DTOs, database entities, and migrations against
    the real implementation.
4.  Testing authentication, authorization, validation, and ownership
    rules.
5.  Verifying payment processing with the actual payment provider.
6.  Ensuring lottery behavior follows the final approved admission
    policy.
7.  Checking security, privacy, and handling of credentials.
8.  Correcting errors and documenting material design decisions.

## 4. No Fabricated Testing Claims

Do not claim that a feature, API, migration, security control, or test
has passed unless it has actually been executed and verified.

A code example or suggested command is not evidence of a successful
build or test. Test results should be recorded only after running the
relevant checks.

## 5. Sensitive Information

Do not submit or commit real passwords, database connection strings, JWT
signing keys, OAuth client secrets, payment credentials, private student
records, or other confidential information to AI tools or public
repositories.

Use placeholders in documentation and development examples.

## 6. Academic and Project Integrity

AI assistance should be disclosed according to the institution's or
evaluator's rules. The developer should be able to explain the
architecture, business rules, code, and design decisions independently.

AI assistance does not replace the developer's responsibility for
correctness, originality requirements, citations, or compliance with the
assignment instructions.

## 7. Disclosure Statement

This project may include code, explanations, documentation, and
troubleshooting suggestions prepared with AI assistance. All such
material must be reviewed, adapted to the actual project, and tested by
the developer before it is represented as a completed or verified
implementation.
